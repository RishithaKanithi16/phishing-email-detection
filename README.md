# Phishing Email Detection Model

## Overview

This project implements a machine learning model for detecting phishing emails using Scikit-learn. The model is trained on a dataset containing both phishing and legitimate emails and uses text analysis techniques to classify emails as either Phishing or Safe.

## Features

* Email text preprocessing
* URL extraction and analysis
* Keyword-based feature extraction
* Email classification using Machine Learning
* Accuracy evaluation
* Confusion Matrix generation

## Technologies Used

* Python
* Scikit-learn
* Pandas
* NumPy
* Matplotlib

## Workflow

1. Load phishing and legitimate email dataset
2. Preprocess email text
3. Extract important features
4. Train machine learning classifier
5. Evaluate model performance
6. Predict whether new emails are Phishing or Safe

## Expected Outcome

The model accurately identifies phishing emails based on suspicious content, URLs, and common phishing indicators.
